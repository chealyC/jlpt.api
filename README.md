# JLPT API

A Python FastAPI project that provides JLPT practice questions, vocabulary and kanji through API endpoints, designed for Japanese language learning and quiz applications.

## Features

* JLPT-like practice questions
* Japanese language learning API
* FastAPI REST endpoints

## Technologies

* Python
* FastAPI
* Uvicorn

## Running the API

Clone the repository and install the dependencies:

```bash
pip install -r requirements.txt
```

Start the server:

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://127.0.0.1:8000
```

Interactive API documentation is available at:

```text
http://127.0.0.1:8000/docs
```
